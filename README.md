# 🎧 EarBalancer EQ

> **"소리가 한쪽으로 쏠려 들리나요? 내 귀에 딱 맞게 머리 정중앙으로 소리를 모아보세요!"**

사람마다 양쪽 귀가 소리를 느끼는 크기가 조금씩 달라요. 이어폰이나 헤드폰을 꼈을 때 왠지 모르게 한쪽으로 소리가 쏠려 들린 적이 있으신가요?

**EarBalancer EQ**는 딱딱하고 어려운 전문 지식 없이도, 양쪽 귀의 밸런스를 0.1dB 단위로 섬세하게 맞춰서 **소리가 내 머리 한가운데에서 똑바로 들리도록 교정해주는 윈도우용 프로그램**입니다.

---

## ✨ 이런 분들께 추천해요!

* 이어폰을 끼면 소리가 미세하게 왼쪽이나 오른쪽으로 치우쳐 들리는 분
* 특정 음높이(낮은 저음이나 높은 고음)에서만 유독 한쪽 귀가 작게 들리는 분
* 보청기처럼 덜 들리는 쪽 귀의 소리를 자연스럽게 채워주고 싶은 분
* 윈도우 무료 사운드 조절 프로그램인 **Equalizer APO**를 쉽고 편하게 쓰고 싶은 분

---

## 🚀 사용 방법 (4단계로 끝내기)

### 1단계: 이어폰 끼고 편하게 준비하기
* 조용한 방에서 평소 자주 쓰는 이어폰이나 헤드폰을 편하게 착용해주세요.
* 🎧 *팁: 이어폰을 얼마나 깊숙이 꼈는지, 헤드폰을 어떻게 썼는지에 따라서도 소리가 다르게 느껴질 수 있어요.*

### 2단계: 소리 듣고 머리 정중앙으로 모으기
* 31개의 음높이(주파수)마다 소리를 들어보면서 슬라이더를 살짝 움직여보세요.
* 화면의 머리 그래픽에서 소리 점이 정중앙 초록색 원 안에 쏙 들어오도록 맞추면 끝!
* 💡 **조절 꿀팁**: 잘 들리는 쪽을 깎아내리기보다, 보청기처럼 **덜 들리는 쪽 귀의 볼륨을 살짝 올려서(+)** 맞추면 소리가 답답하지 않고 훨씬 시원해요!

### 3단계: 원래 소리랑 비교해보기
* 좋아하는 음악을 직접 올려서(내 음악 열기) 보정 전 소리(Option A)와 맞춤 소리(Option B)를 실시간으로 비교해보세요.
* 끊김 없이 소리가 바뀌기 때문에 어느 쪽이 더 편안한지 바로 귀로 확인할 수 있어요.

### 4단계: 윈도우에 저장해서 평소에도 쓰기
* 화면에서 **[설정 파일 다운로드]** 버튼을 눌러 `.txt` 파일을 받습니다.
* 윈도우 무료 프로그램인 **Equalizer APO** 폴더에 쏙 넣어주기만 하면, 유튜브나 넷플릭스, 게임을 할 때도 내 귀에 맞춘 균형 잡힌 소리로 감상할 수 있어요.

## 🖥️ 내 컴퓨터에서 실행하는 방법

### 1. 바로 창으로 띄우기 (추천)
* 폴더 안에 있는 `run-desktop.bat` 파일을 더블 클릭하면 인터넷 주소창 없는 깔끔한 프로그램 창으로 바로 열립니다.

### 2. 개발 환경에서 실행하기
```bash
# 1. 필요한 부품 설치
npm install

# 2. 실행
npm run dev
```
* 브라우저에서 `http://localhost:3000`으로 접속하시면 됩니다.
